# 镜头视角标注台(camera-angle-studio)节点插件

给 Infinite Canvas 扩展一个「镜头视角标注台」节点:在场景图上拖拽箭头标注新机位与拍摄方向,
顶部参数胶囊与右侧提示词文本域**实时联动**,一键生成新视角画面。

**本期纯 UI + 提示词实时联动,生成一律 mock,不发任何网络请求。**

## 节点三态(状态存 `metadata.stage`,刷新恢复)

| 状态 | 外观 |
|---|---|
| `empty` | 虚线框上传入口(点击选择场景图,本地 FileReader 读为 dataURL) |
| `ready` | 场景图缩略 + 「打开标注台 →」按钮(双击场景图也可进入) |
| `generated` | ready 基础上,底部新增 3 个「新视角」小缩略排 + 「继续标注」 |

## 全屏标注台(双击进入,Esc / X 退出)

层内接管全部 pointer 事件并 `preventDefault` contextmenu。

### 画布交互(左区)
- **左键拖拽**画红色箭头:尾圆 = 机位,箭头尖 = 拍摄方向;再次拖拽直接替换旧箭头。
- **长度 → 焦段** 18-200mm。
- **杆粗 → 光圈** f/1.4 - f/16(粗 = 大光圈)。
- **垂直分量 → 俯仰** ±45°(箭头向上 = 仰拍,向下 = 俯拍)。
- **右键拖拽 → 纵深轴**「朝画面前方退出」(左键拖拽 = 深处推进)。
- **滚轮**微调光圈档位。
- **回车**触发生成(mock)。

### 顶部参数标签条(红底红字胶囊,实时刷新)
`焦段{N}mm | 光圈 f/{x} | 左右·朝画面{左|右}侧 | 上下·{仰|俯}拍约{N}° | 纵深·朝画面{前方退出|深处推进}`

### 右侧面板
- **上半部「镜头方向规则」**:标题红色小字、正文灰色、规则条目前红色小方块 ■。
- **下半部「生成新视角」**:
  - 深色文本域,标题「改视角指令(按箭头焦段与光圈自动生成)」;
  - 内容按需求模板**实时拼接**——箭头任何参数变化立即重算;
  - **用户编辑保护**:一旦手动编辑过文本域,拖动箭头不再覆盖,右上出现「恢复自动生成」按钮,点击回到联动模式;
  - 设置行:分辨率(2K/4K)、画质(高质量/超高质量)、画幅比例(16:9/9:16/1:1/自定义数字输入 `n:1`);
  - 红色大按钮「生成新视角」→ toast「已提交,预计30秒」。

### 底部结果流
「新视角画面」标题 + 横排 3 个占位缩略,每个下方「发送到画布」按钮(mock toast)。

## 参数 → 提示词映射

- **焦段注释**:≤24mm 超广角 / 25-35mm 广角 / 36-70mm 标准 / 71-135mm 中长焦 / ≥136mm 长焦。
- **光圈注释**:f/1.4-2.0 大光圈 / f/2.8-4.0 中等 / f/5.6-8.0 小 / f/11-16 极小。
- **纵深轴文案**:右键拖拽 = 前方退出,左键拖拽 = 深处推进(固定)。

## 视觉规范

- 全屏深色底(近黑 `#0d0d0f`),红色 `#e63c3c` 主色贯穿:箭头、参数胶囊、生成按钮、标题点缀。
- 箭头带红色外发光(`feDropShadow`),机位端实心圆 + 白色描边。
- 右侧面板:标题红色小字、正文灰色、规则条目前红色小方块。

## 构建 / 安装

```bash
cd plugins/canvas/camera-angle-studio
npm install
npm run build        # ESM → dist/camera-angle-studio.js + 同步 web/public/plugins/
npm run build:umd    # UMD → dist/camera-angle-studio.umd.js(挂 window.CameraAngleStudioPlugin)
```

**安装 URL(画布「节点插件」管理器填写)**:
```
http://localhost:3000/plugins/camera-angle-studio.js
```
本地开发时画布会自动发现 `web/public/plugins/` 下的插件(默认关闭,打开开关即启用)。

> UMD 说明:画布宿主加载插件走 ESM 版本;`camera-angle-studio.umd.js` 为独立演示/交付用
> (script 标签引入,自带 React 副本,挂 `window.CameraAngleStudioPlugin`),不注入宿主。

## 宿主依赖

复用既有 `fullscreenPanel` 机制(视口级 fixed 容器渲染全屏 Panel,不受画布缩放变换影响),
无新增宿主改动。

## 验收重点

拖动箭头时,顶部胶囊数值与右侧提示词文本域必须**同步实时变化**:
- 提示词生成逻辑在 `src/format.ts`(纯函数),拖动 `pointermove` 时直接 `setState` 重算,无延迟;
- 手动编辑文本域后进入用户保护模式,箭头不再覆盖;点「恢复自动生成」回到联动。
